## 📱 Calculadora de IMC

Projeto Android desenvolvido em Kotlin na disciplina de Tecnologias Móveis.

Baseado no projeto fornecido por Ramon dos Santos Lummertz.
🔗 Projeto base:
https://github.com/ramonsl/Programacao_de_dispositivos_moveis/tree/master/Celula_03/Bloco_01/IMC

### 🧪 Funcionalidades
- Cálculo de IMC
- Exibição de dados do usuário
- Classificação do resultado
- Validação de campos
- Simulação de bateria abaixo de (20%) no emulador

### ✔ Melhorias realizadas
- Interface estilizada com Material Design
- Cores personalizadas
- Resultado com 2 casas decimais

### 🏸 Testes
- Testes unitários básicos para cálculo do IMC
